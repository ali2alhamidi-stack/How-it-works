# وجهة التسليم والتشغيل

المستودع المعتمد: https://github.com/ali2alhamidi-stack/How-it-works

اعتمد المستخدم GitHub لتسليم المصدر بعد اكتمال العمل. المستودع كان فارغا عند فحصه؛ النسخة المركزية وتطبيق المنشأة ولوحة مالك المنصة تنتمي إلى المشروع نفسه.

تخزين الكود على GitHub لا يشغّل خادم Node.js أو قاعدة SQLite. التشغيل المركزي يستخدم `npm start` على بيئة Node.js 24 بتخزين دائم وHTTPS. يمكن استخدام قوالب النشر في deploy بعد ضبط الدومين والنسخ الاحتياطي.

تطبيق Windows وAndroid هو PWA يثبت من المتصفح، وليس حزمتي APK وEXE. لا توجد بيانات دخول إنتاجية أو قواعد عملاء ضمن المستودع.
