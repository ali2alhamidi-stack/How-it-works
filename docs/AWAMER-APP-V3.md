# أوامر · تحديث الهوية وتجربة التطبيق

إصدار تحسين واجهة نظام أوامر العمل والتشغيل على نفس الخادم والمستودع، دون حذف محركات التشغيل والمحاسبة غير المطلوبة أو تغيير مخطط SQLite.

## الهوية
- يستخدم النظام الشعار المصور الذي قدمه مالك المنتج (نسخة مضغوطة ملائمة لواجهة الويب) في الدخول والشريط الجانبي وملفات الطباعة.
- ألوان التطبيق الكحلي #073454 والذهبي #c89c45 والتركواز #087f88. تحتفظ المنشآت بحق تغيير الاسم والشعار والهوية الخاصة بها داخل إعدادات الشركة والوثائق.
- أسماء جميع الأقسام ظاهرة في الشريط الجانبي الافتراضي للكمبيوتر؛ يمكن طي القائمة بمفتاح واضح وحفظ الاختيار محليا. على الجوال يظهر الشريط كاملًا عند فتح القائمة، دون حذف الأقسام.

## خطوات البداية
قسم «ابدأ هنا» دليل عملي مرتبط بحالة بيانات المؤسسة وصلاحيات المستخدم، ويعرض خطوات إضافة الفروع والموظفين والخامات والعملاء وأول أمر عمل ومراحل التسليم. يفتح القسم المرتبط بكل خطوة، دون تغيير بيانات العميل آليًا أو تكوين سجلات تجريبية في الإنتاج.

## المستندات
القسم «المستندات والطباعة» يتيح طباعة أمر العمل وعرض السعر ومحضر التسليم وتقرير التكاليف، مع هيدر وهوامش وتوقيعات وتنسيق A4. يمكن اختيار «حفظ إلى PDF» من قائمة الطباعة في المتصفح المدعوم. عرض السعر ليس فاتورة ضريبية، وتكاليف الإنتاج مقيدة بصلاحية مالية.

## التثبيت
النسخة الحالية PWA قابلة للتثبيت على Windows عبر Edge/Chrome وعلى Android عبر Chrome من الرابط العام الآمن HTTPS. الملفات التنفيذية الأصلية الموقعة Windows EXE وAndroid APK ليست ضمن هذا التحديث؛ تتطلب بنى وتوقيع واختبارات أجهزة حقيقية.

## الجودة
تحقق GitHub Actions من اختبارات منطق الصلاحيات والمزامنة وملفات الـPWA المتولدة. ينبغي إجراء اختبار واقعي على جهازين قبل اعتماد العرض التجاري.
