# دليل واجهات أوامر — الهوية وطريقة بدء العمل والمستندات

## الهوية

الواجهة تستخدم الهوية الرسمية «أوامر» باللون الكحلي والذهبي والتركوازي. تم تحويل الشعار المرفق إلى نسخة متجهية لاختصار الحجم والحفاظ على قراءة الاسم، مع تصميم أيقونة تطبيق تحمل فكرة الأمر وقائمة المهام. بيانات وشعار المنشأة المستقلة تظل في إعدادات العميل ومستنداته حسب الصلاحيات، ولا تتحول جميع المنشآت إلى اسم واحد.

## مسار المستخدم الجديد

- مالك المنصة يسجل الدخول إلى لوحة المنصة وينشئ المؤسسة من قسم «المنشآت والاشتراكات».
- مالك المؤسسة يدخل حسابه، يفتح **ابدأ هنا**، ويتحقق من خطوات الهوية، الفروع، الموظفين، الخامات، العملاء ثم أول أمر عمل.
- تظهر حالة الخطوات من البيانات المسجلة، دون ملء تلقائي أو إنشاء أرصدة وهمية.
- الموظف يرى شرحًا مختلفًا لاستلام مهمته وتوثيقها.
- توجد تلميحات مختصرة للصفحات الأساسية مع رابط الرجوع للدليل.

## الشريط الجانبي

يُعرض الاسم مع الأيقونة في كل قسم على الكمبيوتر، ويمكن تصغيره وإعادته إلى الحجم الكامل. على شاشة الهاتف يتحول إلى قائمة جانبية تفتح من زر القائمة؛ لا يُخفى اسم القسم عند فتحها. يُحفظ تفضيل تصغير الشريط في هذا الجهاز.

## المستندات

من تفاصيل أمر العمل توجد:
1. **أمر عمل وتشغيل**: مواصفات الورشة والموعد والصور والفريق، وتكاليف داخلية للمخولين فقط.
2. **عرض سعر**: للمالك أو المدير المخول ماليا فقط، دون تكاليف الشراء أو تفاصيل أرباح الشركة. ليس فاتورة ضريبية.
3. **محضر تسليم واستلام**: لا يصدر إلا بعد تسجيل حالة تسليم الأمر، مع حقول توقيع.
4. **إثبات مراجعة التصميم**: لا يصدر إلا بعد تسجيل موافقة العميل على أحدث إصدار، ولا يعد توقيعا إلكترونيا قانونيا.

تستخدم المستندات مقاس A4 وتنسيقا عربيًا واضحًا. زر الطباعة يفتح شاشة النظام للطباعة، ومنها يمكن اختيار **حفظ PDF** عبر Chrome أو Edge، دون الادعاء بوجود محرك PDF مستقل على الهاتف.

## التثبيت

هذه النسخة **PWA** قابلة للتثبيت على Windows وAndroid من Chrome أو Edge عند ظهور خيار التثبيت. التثبيت ليس حزمة Windows EXE ولا Android APK، ولا يثبت أن الجهاز قد اجتاز اختبارات التشغيل الميدانية. العمل غير المتصل يظل خاضعا لحدود المسودات والعمليات المؤجلة والمزامنة كما هو موثق مسبقًا.

## اختبار القبول

تأكد من صلاحيات المالية، اختيار الفرع، استمرارية المسودات، استخدام أزرار الطباعة، عدم كشف التكلفة في مستند العميل، ومظهر الواجهة على الهاتف والكمبيوتر. لا تستبدل اختبار الموظفين على الأجهزة الفعلية باجتياز فحص بناء GitHub فقط.
