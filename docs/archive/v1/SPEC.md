# نظام أوامر العمل والتشغيل — نطاق النسخة الأولى

تاريخ: 2026-11-13. المطلوب نسخة واجهة تشغيلية محلية تفاعلية كاملة قبل ربط الخادم وGitHub، وليست نظام محاسبة. المستخدم أذن بالتنفيذ والقرارات التصميمية والإضافات المناسبة دون انتظار أسئلة.

## الوظائف
- هوية افتراضية آرت بلس قابلة لتغيير الشعار والاسم والألوان والعملة والكليشة.
- مدير مالك، مدير فرع، موظف، مشتريات. صلاحيات وفروع مستقلة في العرض والعمليات المحلية.
- الرئيسية، كتالوج خدمات الدعاية، العملاء، أوامر العمل، خط الإنتاج، بوابة الموظف، المخزون والبواقي، المشتريات، الفريق، الفروع، التقييمات، التقارير، الحاسبات، الإعدادات.
- إنشاء وتعديل أوامر العمل، موافقة التصميم، مراحل التنفيذ، فريق متعدد مع حصص 100%، وقت وتسليم وصور وملاحظات وسجل أحداث.
- حجز بواقي خامة لأمر واحد، صرف خامات وتوثيق الهدر والبواقي المؤكدة من الموظف. طلب شراء ثم موافقة ثم استلام يمنع تكرار زيادة المخزون.
- أسعار البيع وتكاليف الخامات والعمل والمصاريف التشغيلية للأمر وهامش مساهمة؛ لا قيود أو دليل حسابات أو ادعاء صافي أرباح شامل.
- تقييم عميل دون حساب عبر رابط ورمز QR، الاسم اختياري، نص بأن التقييم يصل للإدارة. عرض محلي صريح حتى ربط API.
- شهريا: الإنجاز الموزع والالتزام والوقت وتقييم العميل مع تفسير التقييم وعدم اختلاق درجة عند غياب البيانات.
- الحاسبات: قص مستطيلات أكريلك/داي كت مع هامش وفاصل قطع وتدوير، طباعة ورقية وتكرار على الورقة، بنر/فلكس/فينيل وأحبار، حروف وشعار بحد أدنى متر (الشعار ×2)، ليدات وشرائط وترانس، تكاليف عامة وأختام وهدايا ومجسمات.
- الحروف: افتراض معلن ارتفاع احتساب الحرف max(1,heightMeters)، مضروب العدد وسعر المتر. الشعار max(1,heightMeters)×2×quantity×rate. الارتفاع فوق المتر فعلي افتراض قابل للتعديل؛ لا تقريب إضافي إلا إذا اختير.
- LED: حساب قدرة وتيار وعدد مزودات ومجموعات وتقدير طول/عدد، استنادا إلى مواصفات الوحدات المدخلة. 80% تحميل افتراضي قابل للتعديل وليس قاعدة عامة لكل منتج. يراجع الفني المخطط النهائي.

## الحدود الصادقة
تخزين محلي وحسابات عرض تجريبية لا تشكل حماية أمنية أو مصادقة متعددة مستخدمين. لا إرسال WhatsApp أو خادم أو مزامنة أجهزة أو استقبال تقييمات عن بعد. هذه وظائف التكامل التالي. جميع الوظائف المحلية تعمل وتتسجل وتصدر وتطبع. لا يتم الادعاء بأن Native Windows/APK أو Backend جاهز.

## الواجهة
RTL، عربية بلا تشكيل، أبيض وبنفسجي وتركواز، أيقونات مربعة ملونة، واجهة هاتف مخصصة مع شريط سفلي، سطح مكتب بصفحة واسعة وشريط جانبي ومحتوى واضح، بحث فوري، وضع داكن، لا نوافذ منبثقة للنماذج الأساسية.
